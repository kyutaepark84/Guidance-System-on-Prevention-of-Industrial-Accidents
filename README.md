# 재해예방 기술지도 관리시스템 (DEMO)

산업안전보건법 제73조(건설공사의 산업재해 예방 지도)에 따른 **재해예방 기술지도**를 사업주(Owner)가 주관하여 관리하기 위한 DEMO 시스템입니다.
공사(일반·단가계약)의 **기술지도 대상여부를 자동 판정**하고, 협력업체 관리부서 · 안전보건환경부서 · 기술지도기관 · 협력업체 · 구매부서가
**상태(State) 기반 업무 흐름**에 따라 각자의 업무를 수행하도록 지원합니다.

> DEMO의 목적: 각 주관 부서·기관·협력업체가 함께 시험 운영하며 개선사항을 도출하고, 향후 사내 시스템 구축의 기초자료로 활용.

## 1. 실행 방법 (사내 PC/서버에서 직접 실행)

```bash
# Node.js 18 이상
npm install
npm start            # http://localhost:3000
```

- 최초 실행 시 시연용 데이터(가상 업체·기관·사용자·공사 9건)가 자동 생성됩니다. (`data/` 폴더)
- 다시 초기화: 화면 `DEMO 운영·기준정보 → 시연 데이터로 초기화` 또는 `TG_RESEED=1 npm start`
- 포트 변경: `PORT=8080 npm start` / 데이터 위치 변경: `TG_DATA_DIR=/경로 npm start`
- 사내망 PC 1대에서 실행하고 다른 사람은 `http://<PC의 IP>:3000` 으로 접속하면 여러 부서가 같은 데이터로 함께 테스트할 수 있습니다.
- 테스트: `npm test` / 샘플 파일 재생성: `npm run samples`

### 로그인(DEMO)
첫 화면에서 **테스트할 사용자(역할)를 선택**합니다. 상단 사용자 선택 상자로 언제든 역할을 전환할 수 있어,
한 사람이 구매 → 협력업체 → 기술지도기관 → 협력업체 관리부서 순으로 업무 흐름 전체를 시연할 수 있습니다.
(DEMO는 비밀번호가 없습니다. 사내 구축 시 SSO 연동 필요)

## 2. 시스템 구현 순서도 ↔ 구현 내용

| 순서도 | 구현 | 담당 |
|---|---|---|
| **1. 공사 정보 등록** | `기술지도 대상 공사 구분 → 신규 공사 등록`에서 공사 계약서 Upload → 공사계약명·업체명·계약기간·계약금액(+계약번호, 단가계약 여부) **자동 추출** → 확인/수정 후 등록. PDF(텍스트)·DOCX·HWPX·XLSX·TXT 지원, 한글 금액(일금 일억오천만원정) 인식, 추출 근거 문장 표시 | 구매부서 |
| **2. 대상여부 자동 판단** | 일반: 기간 1개월↑ **AND** 금액 1억↑ / 단가: 계약금액 1억↑, 또는 **연간 누적 정산금액 1억↑**. `단가계약 정산·누계`에서 월별 정산실적(엑셀/CSV) Upload → 계약별 누계·기준 대비 %·연말 예상 누계 표시, 1억 도달 시 **자동으로 대상 전환** | 시스템 / 구매·관리부서 |
| **3. 대상 공사 자동 안내** | 대상 판정 즉시 협력업체 관리부서·협력업체·기술지도기관·안전보건환경부서에 E-메일+SMS. 공사정보·기술지도 대상기간 + 수신자별 조치사항(협력업체: 자료 Upload / 기관: 계약서 Upload) | 시스템 |
| **4. 자료 Upload 제출** | 협력업체: 공사계약서·산재보험 가입증명서·사업자등록증(필수) Upload → 제출 / 기관: 자료 검토 → **보완요청** 또는 **기술지도 계약서 Upload** → 기술지도 개시 | 협력업체 → 기관 |
| **5. 기술지도 진행** | (1) 협력업체 월별 작업일자 지정(달력) → 기관이 작업일 중 지도일 선택 → 4개 주체 자동 안내 (2) 기관 결과 제출(사후), 보완요구 시 협력업체 개선결과 보고 → 기관 검토 (3) **만료 D-15 자동 안내**(종결 조치 / 연장 서류 제출) (4) 협력업체 관리부서 종결 | 각 주체 |
| **6. 기간 연장** | 연장 요청 → ① 구매: 갱신 계약서(단가: 가계약서/본계약서) → ② 협력업체: 갱신계약서 또는 납품연기원 + 산재가입증명서 갱신 → ③ 기관: 추가계약서. 순서 강제, 완료 시 지도기간 자동 연장 및 D-15 재안내 | 구매 → 협력업체 → 기관 |
| **7. 구현 불필요** | 승인/결재 절차 없음(안전보건 '확인' 기록만), 비용 정산 제외 | – |

### 추가로 넣은 "기술지도 누락 방지" 기능
- **15일 1회 주기 점검**: 직전 지도일(또는 개시일) + 15일 = 다음 지도 기한. 일정 미지정 시 사전안내, 기한 초과 시 경보(관계자 메일/SMS, 대시보드 빨간 경보)
- **결과 미제출 안내**: 지도일 2일 경과 후 결과 미제출 시 기관·관리부서에 안내
- **기간 경과 경보**: 기술지도 기간이 지났는데 종결/연장이 안 된 경우
- **단가계약 누계 주의**: 누계가 기준의 80% 이상이거나 현 추세로 연말 1억 초과가 예상되면 관리부서·안전보건에 안내 (운영방안 "누적 1억원 미만 관리" 지원)
- **내가 처리할 업무**: 상태별 현재 담당(Ball-in-court)을 계산해 역할별 대시보드에 표시
- 같은 안내는 중복 발송하지 않음, 모든 처리는 이력(타임라인)으로 기록, 공사 목록 엑셀 내보내기

### 시간 경과 시뮬레이션 (시연용)
`시스템관리자`로 로그인 → `DEMO 운영·기준정보`에서 **데모 기준일**을 +1/+7/+15/+30일 앞당기면 D-15 안내, 주기 초과 경보 등이
즉시 실행되어 결과를 확인할 수 있습니다. 판정 기준값(1억원, 1개월, 80%, 15일 등)도 이 화면에서 바꿀 수 있습니다.

## 3. 시연 시나리오 (약 10분)

1. **김구매(구매부서)** → 공사 구분 → 신규 공사 등록 → `samples/공사계약서_일반공사_샘플.docx` Upload → 자동 추출 확인 → 등록 ⇒ "기술지도 대상" 판정 + 자동 안내
2. **오소장(동해기전, 협력업체)** → 공사 상세 → 관련자료 3종 Upload → 제출
3. **강지도(기술지도기관)** → 자료 검토 → 기술지도 계약서 Upload (또는 보완요청 시험)
4. **오소장** → 월별 작업일자 달력에서 선택 → 저장
5. **강지도** → 작업일 중 지도일 선택 ⇒ 4개 주체에 지정일 안내
6. **시스템관리자** → 기준일 +30일 → **강지도** 결과 제출(보완요구 체크) → **오소장** 개선결과 보고 → **강지도** 확인
7. **박정비(정비팀, 협력업체 관리부서)** → 연장 요청 또는 종결
8. **이계전(계전팀)** → 단가계약 정산·누계 → `samples/단가계약_월별정산실적_샘플.xlsx` Upload ⇒ 2공장 계장정비 단가공사가 누계 1억 초과로 **자동 대상 전환·안내**
9. 각 사용자의 `알림(메일·SMS)`에서 실제로 받게 될 메일/SMS 내용 확인

## 4. 구성

```
server/
  index.js       REST API, 파일 업/다운로드, 엑셀 내보내기, 스케줄러 기동
  rules.js       기술지도 대상 판정 규칙 (일반/단가/누계/예측)
  workflow.js    상태 머신, 역할별 권한, 액션, 할 일 계산, 일일 점검(D-15·주기·누계)
  extract.js     계약서 텍스트 추출(PDF/DOCX/HWPX/XLSX/TXT) 및 필드 추출
  settlement.js  월별 정산실적 엑셀/CSV Upload, 양식 생성
  notify.js      메일/SMS 발송(DEMO: 기록만) — 사내 게이트웨이 연동 지점
  db.js          JSON 파일 저장소(data/db.json, data/uploads/)
  seed.js        시연 데이터
public/          화면 (빌드 불필요, 외부 CDN 미사용 → 인터넷 차단 사내망에서도 동작)
samples/         시연용 계약서·정산실적 샘플
test/            판정 규칙·추출·업무 흐름 통합 테스트 (npm test)
docs/            사내 시스템 구축용 설계 메모
```

## 5. DEMO의 한계 (사내 구축 시 보완)
- 메일/SMS는 실제 발송하지 않고 기록만 합니다 → `server/notify.js`의 `deliver()`를 사내 SMTP/SMS 게이트웨이로 교체
- 로그인 없음(사용자 선택) → 사내 SSO/권한 체계 연동
- 계약서 자동 추출은 규칙 기반이며 스캔 이미지 PDF, 구버전 HWP는 미지원(직접 입력) → 구매시스템 계약정보 연동으로 대체 권장
- 정산실적은 엑셀 Upload → SAP 월별 정산금액 인터페이스로 대체
- JSON 파일 저장(단일 서버) → RDB 전환. 상세는 [docs/사내구축_설계메모.md](docs/사내구축_설계메모.md)

※ 시연 데이터의 업체·기관·인물은 모두 가상입니다.
